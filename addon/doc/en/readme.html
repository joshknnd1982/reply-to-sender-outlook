Reply to Sender for Microsoft Outlook

  • Author: Josh Kennedy
  • Version: 0.1
  • Compatibility: NVDA 2024.1 through 2026.1

Overview

This add-on adds one command to NVDA inside Microsoft Outlook: NVDA+shift+r (works with either the insert or caps lock NVDA modifier key). It replies directly, and only, to the original sender of the message you are reading.

The add-on is implemented as an Outlook app module, so it is only active while Microsoft Outlook is running and focused. When you close Outlook with the close button or alt+f4, NVDA unloads the add-on automatically.

What the command does

  1. Ensures the current Outlook window is maximized.
  2. Reads the From field of the current message and copies the sender's email address to the clipboard.
  3. Invokes Outlook's reply command and waits for the reply window to gain focus (the reply window is also maximized).
  4. Erases whatever Outlook put in the To field and fills it with only the original sender's email address, guaranteeing the reply goes to the sender alone.
  5. Moves focus to the very top of the message body and announces "message body, begin typing."

Usage

Open a message, or select one in the message list, then press NVDA+shift+r. When you hear "message body, begin typing," just type your reply and send it as usual (control+enter or alt+s).

Notes

  • The command works on mail messages. For items that cannot be replied to, NVDA announces that no reply is possible.
  • For Exchange and Microsoft 365 accounts, the add-on resolves the sender's real SMTP address rather than the internal Exchange address.
  • The gesture can be reassigned in NVDA menu > Preferences > Input gestures, under the "Reply to Sender for Outlook" category (while Outlook is focused).
